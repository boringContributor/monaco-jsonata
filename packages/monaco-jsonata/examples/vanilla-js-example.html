Monaco JSONata - Vanilla JavaScript Example

Features Available:

  • Syntax Highlighting: JSONata-specific tokenization
  • Auto-completion: Type $ to see all JSONata functions
  • Hover Documentation: Hover over functions to see documentation
  • Signature Help: Type a function name and ( to see parameters
  • Real-time Diagnostics: Parse errors are highlighted automatically
  • Formatting: Click "Format Code" or press Shift+Alt+F
